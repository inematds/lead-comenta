Começar o guia Ver no GitHub
Em resumo

O lead-comenta cria a página do "guia grátis" que você promete quando diz no post "comenta PALAVRA que eu te mando". Serve para quem posta reel ou carrossel com esse convite e precisa ter o material pronto antes de publicar. Você dá a palavra, o tema e uma fonte (uma página na internet ou um arquivo de texto seu); ele escreve um guia curto de 4 a 7 passos só com o que está na fonte, publica a página no GitHub Pages (o serviço grátis do GitHub que deixa páginas no ar) e prepara os textos de resposta. Ele não manda mensagem sozinho: hoje você cola a resposta no direct à mão. Para usar, precisa de Python 3, do Claude Code e de uma conta no GitHub.

O que é

O material grátis pronto antes do post

Uma página por palavra, com o conteúdo conferido e as respostas escritas. Você só confere e responde.

📄 Uma página por palavra

Cada palavra vira um endereço próprio, do tipo .../paginas/agente/: título, para quem é, de 4 a 7 passos, um cuidado e o link para o material completo. Abre bem no celular e tem botão de copiar nos textos de exemplo.

🔒 Só o que está na fonte

O Claude escreve o guia só com o que está na página ou no arquivo que você indicou, sem inventar número nem ferramenta. Se a fonte tem pouco conteúdo, o guia sai curto. Você lê antes de publicar.

✍️ Respostas prontas para colar

Para cada palavra sai um respostas.md com três textos: a resposta no comentário (sem link, porque o Instagram tende a esconder comentário com link), a mensagem do direct com o link e o texto do story.

Como funciona

Do comentário à página no ar

Um comando gera tudo; você confere e publica. O texto é escrito pelo Claude Code rodando sem janela (claude -p), pela sua assinatura: não usa chave de API paga.

Palavra + tema→ Fonte (link ou arquivo)→ Guia de 4 a 7 passos→ Página + respostas.md→ Você confere→ git push → página no ar→ Você responde no direct

E a mensagem automática no direct?

Ainda não existe. O lead-comenta não envia mensagem para ninguém: você (ou alguém da sua equipe) abre o direct de quem comentou e cola o texto pronto. As formas de automatizar o envio estão descritas no DECISAO-DM.md e ainda não foram escolhidas.

Pré-requisitos

O que precisa estar no computador

Um computador Linux ou Mac (no Windows, pelo WSL, o Linux que roda dentro do Windows). Os comandos são digitados no terminal, a tela de texto do computador.

Python 3

É a linguagem em que a ferramenta foi escrita. Não precisa instalar nenhum pacote extra. Confira se já tem (no Mac, se faltar: brew install python; no Ubuntu: sudo apt install python3).

python3 --version

Claude Code, já logado

É ele que escreve o guia. Instale pelo site claude.com/claude-code, abra uma vez com claude e entre na sua conta. Precisa de um plano pago do Claude (Pro ou acima). Depois confira:

claude --version

git, gh e conta no GitHub

O git baixa e publica o projeto; o gh é o programa do GitHub para o terminal. A página fica no ar pelo GitHub Pages da sua conta; o arquivo que publica (.github/workflows/pages.yml) já vem no projeto.

Ubuntu ou WSL

sudo apt install git gh

Mac

brew install git gh

Se o Ubuntu disser que não encontrou o pacote gh, siga as instruções de cli.github.com.

Guia de uso · passo a passo

Da palavra ao primeiro guia no ar

Comandos copiáveis, na ordem. Os passos 1 e 2 são feitos uma vez só; do 3 ao 7, uma vez por palavra.

1

Baixe o projeto e teste

Baixa a ferramenta e lista as palavras que já existem. Se aparecer a linha do AGENTE (o exemplo que vem junto), está funcionando.

git clone https://github.com/inematds/lead-comenta ~/lead-comenta
cd ~/lead-comenta
python3 lead.py lista
2

Crie a sua cópia no GitHub (uma vez)

As páginas precisam ficar na sua conta. Primeiro, entre na sua conta do GitHub pelo terminal. A opção --scopes workflow dá permissão para enviar o arquivo que publica as páginas. O comando faz quatro perguntas; responda assim:

  • Onde você usa o GitHub: GitHub.com
  • Protocolo: HTTPS
  • Autenticar o git com a sua conta: Yes (sim)
  • Como entrar: Login with a web browser; copie o código que aparece, aperte Enter e cole o código na página que abrir.
gh auth login --scopes workflow

Na primeira vez, o git também quer saber o seu nome e e-mail para registrar quem enviou cada mudança. Troque pelos seus:

git config --global user.name "Seu Nome"
git config --global user.email "voce@exemplo.com"

Descubra o seu nome de usuário no GitHub; ele aparece na tela. No bloco seguinte, troque SEU-USUARIO por ele. O primeiro comando cria o seu repositório (a pasta do projeto no GitHub), o segundo liga o GitHub Pages nele e o terceiro envia o projeto.

gh api user -q .login
gh repo create lead-comenta --public --source . --remote meu
gh api -X POST repos/SEU-USUARIO/lead-comenta/pages -f build_type=workflow
git push meu main

Por fim, diga à ferramenta qual é o endereço das suas páginas, para o link certo entrar nas respostas. Esse export vale até fechar o terminal; para não repetir, cole a mesma linha no fim do arquivo ~/.bashrc (no Mac, ~/.zshrc).

export LEAD_BASE_URL=https://SEU-USUARIO.github.io/lead-comenta/paginas

A sua cópia vem com o exemplo AGENTE do INEMA, que continua apontando para o endereço do INEMA. Pode deixar como referência ou apagar a pasta paginas/agente e o trecho "AGENTE" do arquivo palavras.json.

3

Escolha a palavra e a fonte

  • Palavra: a mesma que você pede no post. Uma palavra só, de 3 a 14 letras ou números, sem espaço. Ela vira maiúscula e dá o nome da página.
  • Tema: o assunto do post, numa frase.
  • Fonte: de onde sai o conteúdo. Pode ser o link de uma página pública ou um arquivo de texto seu (.md ou .txt). Guarde o arquivo fora da pasta do projeto, na sua pasta pessoal (~): tudo o que fica dentro da pasta do projeto vai para o GitHub, que é público. Para criar o arquivo, abra um editor de texto (no terminal: nano ~/meu-material.md), cole o conteúdo e salve (no nano: Ctrl+O, Enter e Ctrl+X). Confira se a fonte trata do mesmo assunto do post.
4

Gere a página

Troque PROMPT, o tema e a fonte pelos seus. A tela mostra "lendo a fonte…", depois "escrevendo o guia (claude -p)…" e, no fim, "pronto" com o caminho da página. Pode levar alguns minutos.

python3 lead.py nova PROMPT --tema "5 prompts para responder clientes" --fonte ~/meu-material.md

O botão "Ver o material completo" leva à fonte, se ela for um link. Para apontar para outro lugar (seu curso, seu site), acrescente --link-final https://seu-site. Se a palavra já existe, a ferramenta avisa; para gerar de novo por cima, acrescente --refaz.

5

Confira antes de publicar

Abra a página no navegador e leia cada passo: nada pode estar fora do que a fonte diz. O primeiro comando é do Linux; no Mac, troque xdg-open por open; no WSL, por explorer.exe. Se algo não estiver certo, melhore a fonte e gere de novo com --refaz.

xdg-open paginas/prompt/index.html
6

Publique

Envia a página para a sua cópia no GitHub. Ela fica no ar em cerca de 1 minuto (na primeira publicação pode levar alguns minutos; o andamento aparece na aba Actions do seu repositório), no endereço https://SEU-USUARIO.github.io/lead-comenta/paginas/prompt/.

git add -A
git commit -m "guia PROMPT"
git push meu main
7

Responda quem comentou

Mostra os três textos prontos. Para cada pessoa que comentou: primeiro mande no direct dela a mensagem com o link; depois responda o comentário com o texto curto ("Te mandei no direct!"). O texto do story serve para lembrar quem ainda não comentou. Os mesmos textos ficam salvos em paginas/prompt/respostas.md.

python3 lead.py resposta PROMPT
Exemplo

A página da palavra AGENTE

Tema "6 tarefas chatas que um agente de IA já faz por você (pequena empresa)", com o guia de um kit gratuito do INEMA como fonte. Saiu um guia de 6 passos. Abrir a página.

E o respostas.md que saiu junto:

## Resposta pública no comentário (curta, sem link: o Instagram esconde comentário com link)
Te mandei no direct! Se não chegar, me chama por lá com AGENTE.

## Mensagem direta (DM)
Oi! Aqui está o guia grátis que você pediu: **Seu primeiro agente de IA na empresa, passo a passo**
https://inematds.github.io/lead-comenta/paginas/agente/
São 6 passos curtos. Qualquer dúvida, responde aqui.

## Story (texto)
Quem comentou AGENTE: o guia já está no seu direct. Ainda não comentou? Vai no post e comenta AGENTE.
